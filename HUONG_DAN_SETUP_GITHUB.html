Đưa website lên GitHub từ đầu

Hướng dẫn cho dự án ThiepCuoi và GitHub Pages
Quy trình tổng quát: chỉnh mã nguồn → Build Release trong Visual Studio → commit/push lên GitHub → GitHub Pages tự triển khai website.

1. Chuẩn bị

  • Cài Git for Windows.
  • Có tài khoản GitHub và đăng nhập trong Visual Studio hoặc Git Credential Manager.
  • Mở đúng thư mục dự án: D:\5. All_application\ThiepCuoi\webThiepcuoi_customChangetheoconfig.

2. Tạo repository trên GitHub

  1. Vào github.com/new.
  2. Đặt tên repository, ví dụ ThiepCuoi.
  3. Chọn Public.
  4. Không tạo sẵn README, .gitignore hoặc License nếu dự án đã có các file này.
  5. Bấm Create repository.

3. Upload dự án lần đầu bằng PowerShell

Mở PowerShell tại thư mục dự án và chạy:

cd "D:\5. All_application\ThiepCuoi\webThiepcuoi_customChangetheoconfig"
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/ThiepCuoi.git
git push -u origin main

Thay USERNAME bằng username GitHub của bạn.

Nếu repository đã có remote và commit rồi, chỉ cần dùng: git push.

4. Bật GitHub Pages

  1. Mở repository trên GitHub.
  2. Vào Settings → Pages.
  3. Ở phần Source, chọn Deploy from a branch.
  4. Chọn branch main và thư mục /docs.
  5. Bấm Save.

Sau khi build xong, link có dạng:

https://USERNAME.github.io/ThiepCuoi/

5. Cập nhật website bằng Visual Studio

  1. Sửa nội dung trong ThiepCuoi\Config hoặc giao diện trong ThiepCuoi\wwwroot.
  2. Chọn cấu hình Release trên thanh công cụ Visual Studio.
  3. Chọn Build → Build Solution hoặc nhấn Ctrl + Shift + B.
  4. Project sẽ tự xuất website tĩnh vào thư mục docs.
  5. Mở cửa sổ Git Changes, nhập nội dung commit.
  6. Bấm Commit All and Push.

Cấu hình hiện tại chỉ tự export khi build Release. Build Debug không làm thay đổi website GitHub Pages.

6. Nếu thêm file HTML mới

File HTML tĩnh cần được đưa vào thư mục xuất bản docs. Ví dụ:

docs\thong-tin.html

Để file không bị mất ở lần export tiếp theo, hãy thêm logic copy file đó vào publish-github-pages.ps1, rồi build Release lại.

Đường dẫn sau khi deploy sẽ là:

https://USERNAME.github.io/ThiepCuoi/thong-tin.html

7. Lỗi thường gặp

  • 404: kiểm tra Pages đang chọn đúng main → /docs và chờ GitHub build.
  • 403 khi push: Git đang đăng nhập sai tài khoản; đăng nhập lại Git Credential Manager.
  • Ảnh/CSS không tải: kiểm tra đường dẫn tương đối, dùng ./images/... thay vì đường dẫn bắt đầu bằng /.
  • Website chưa đổi: kiểm tra Git Changes đã commit và push chưa, sau đó nhấn Ctrl + F5.

8. Các lệnh cập nhật nhanh

git add .
git commit -m "Update website"
git push
